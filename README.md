# 📊 Sorting Algorithms & Time Complexities

## 🔢 Algorithms

### 🔁 Bubble Sort
- **Best Case:** O(n) — when the array is already sorted
- **Average Case:** O(n²)
- **Worst Case:** O(n²) — when the array is reverse sorted

### 📌 Selection Sort
- **Best/Average/Worst Case:** O(n²) — regardless of input configuration

### ✍️ Insertion Sort
- **Best Case:** O(n) — already sorted input
- **Average Case:** O(n²)
- **Worst Case:** O(n²) — reverse sorted input

### 🔀 Merge Sort
- **Best/Average/Worst Case:** O(n log n) — stable and predictable performance

### 🧮 Heap Sort
- **Best/Average/Worst Case:** O(n log n) — efficient, but not stable

### ⚡ Quick Sort
- **Best/Average Case:** O(n log n)
- **Worst Case:** O(n²) — occurs when pivot selection is poor (e.g., always choosing first/last element)

## 📚 Notes
- Merge Sort is ideal for stability and consistent performance.
- Quick Sort can outperform others in practice, especially with good pivot strategies.
- Simple sorts like Bubble, Selection, and Insertion are useful for small data sets.
